B
Train-Test Split
Divide data — 80% to learn, 20% to test
📚 Like a student studying 80% of the textbook, then being tested on the other 20% they haven't seen. If they pass, they truly learned — not just memorized.
python · Part B 
# Part B - Train-Test Split
from sklearn.model_selection import train_test_split

X = data.data   # 30 features (inputs)
y = data.target  # labels (0=malignant, 1=benign)

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.2,       # 20% for testing
    random_state=42     # fixed seed = same split every time
)

print("Training set size:", X_train.shape)
print("Testing set size: ", X_test.shape)
Discussion Answers
Why split the data?So the model learns on one part and is tested on data it has NEVER seen before — just like a real exam
Purpose of test set?To check if the model truly learned the pattern, or just memorized training data
What is random_state=42?A seed so the split is always the same — for reproducibility. Any number works, 42 is convention.
Expected sizes?Train: ~455 samples | Test: ~114 samples
C
Train Model & Evaluate
Train Random Forest and check how well it performs
python · Part C 
# Part C - Random Forest Classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (
    accuracy_score, precision_score,
    recall_score, f1_score,
    confusion_matrix, classification_report
)

# Create model
model = RandomForestClassifier(n_estimators=100, random_state=42)

# Train it
model.fit(X_train, y_train)

# Make predictions
y_pred = model.predict(X_test)

# Print all metrics
print("Accuracy : ", round(accuracy_score(y_test, y_pred), 4))
print("Precision: ", round(precision_score(y_test, y_pred), 4))
print("Recall   : ", round(recall_score(y_test, y_pred), 4))
print("F1-Score : ", round(f1_score(y_test, y_pred), 4))

print("\nConfusion Matrix:")
print(confusion_matrix(y_test, y_pred))

print("\nFull Report:")
print(classification_report(y_test, y_pred, target_names=data.target_names))
What Each Metric Means
Accuracy
~96%
% of ALL correct predictions out of total
Precision
~95%
Of predicted cancer cases, how many were actually cancer?
Recall
~97%
Of all actual cancer cases, how many did we catch?
F1-Score
~96%
Balance of Precision + Recall in one number
Discussion Answers
What does Random Forest do?Builds 100 decision trees, each slightly different. All trees vote, majority wins — more reliable than one tree
Why not accuracy alone?If 90% of patients are healthy, always predicting "healthy" = 90% accuracy but catches ZERO cancer. Recall reveals this flaw
Confusion Matrix?Shows True Positives, True Negatives, False Positives, False Negatives in a 2×2 grid
n_estimators=100?Number of trees in the forest. 100 trees vote together
D
Feature Importance
Which tumor measurements matter most?
🔍 Like a doctor saying: "I mostly look at the tumor size and shape — those matter most. The color barely affects my decision." Feature importance tells you which of the 30 measurements the model relied on most.
Cell 1 — Table of Importances
python · Part D — Table 
# Part D - Feature Importance
import pandas as pd

importances = model.feature_importances_
feature_names = data.feature_names

# Create a sorted table
feat_df = pd.DataFrame({
    'Feature': feature_names,
    'Importance': importances
})

feat_df = feat_df.sort_values('Importance', ascending=False).reset_index(drop=True)

print("Top 10 Most Important Features:")
print(feat_df.head(10).to_string(index=False))
Cell 2 — Bar Chart
python · Part D — Chart 
# Bar chart of top 10
import matplotlib.pyplot as plt

top10 = feat_df.head(10)

plt.figure(figsize=(10, 6))
plt.barh(top10['Feature'][::-1], top10['Importance'][::-1], color='steelblue')
plt.xlabel('Importance Score')
plt.title('Top 10 Feature Importances — Random Forest')
plt.tight_layout()
plt.savefig('feature_importance.png', dpi=150)
plt.show()
Discussion Answers
Most important features?Typically: worst concave points, worst perimeter, mean concave points — related to shape extremes
What does importance mean?How much each feature helped the trees make correct decisions (split data well)
Does high importance = cause?NO. It means useful for prediction. It does NOT mean that feature causes cancer. Correlation ≠ Causation
How does it help?Doctors can focus on key measurements; we can simplify models by removing unimportant features
